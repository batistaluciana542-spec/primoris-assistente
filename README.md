# PRIMORIS v2.0

Assistente pessoal com interface mobile, agenda local, estudos, oportunidades, memória, Google Calendar, Google News e integração opcional com IA.

## Render
Use Node e o comando `npm start`.

Variáveis:
- SESSION_SECRET
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_REDIRECT_URI
- OPENAI_API_KEY
- OPENAI_MODEL

Nunca coloque segredos reais no GitHub.
